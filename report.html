CRITICAL vsftpd 2.3.4 backdoor21/tcp

Evidence: vsftpd 2.3.4 detected on 21/tcp (vsftpd 2.3.4)

Why it matters: This vsftpd release shipped with a backdoor that opens a root shell when a username ending in ':)' is sent.

Recommendation: Remove or upgrade vsftpd immediately and treat the host as compromised.

References: CVE-2011-2523

HIGH Anonymous FTP login allowed21/tcp

Evidence: NSE ftp-anon on 21/tcp (vsftpd 2.3.4): Anonymous FTP login allowed (FTP code 230)

Why it matters: Anyone can read (and possibly write) files on this FTP server without credentials.

Recommendation: Disable anonymous access or restrict it to a read-only, non-sensitive directory.

HIGH Telnet service exposed23/tcp

Evidence: Telnet service open on 23/tcp (Linux telnetd)

Why it matters: Telnet transmits credentials and data in clear text.

Recommendation: Disable Telnet and use SSH instead.

HIGH Database service exposed3306/tcp

Evidence: Database service (mysql) open on 3306/tcp (MySQL 5.0.51a-3ubuntu5)

Why it matters: A database listening on the network is reachable by attackers for brute force and exploitation.

Recommendation: Bind the database to localhost or a private interface and filter the port.

MEDIUM FTP without encryption21/tcp

Evidence: FTP without TLS on 21/tcp (vsftpd 2.3.4)

Why it matters: FTP sends credentials and files in clear text.

Recommendation: Use SFTP or FTPS.
